Projeto MVP - Pós Graduação PUC-Rio - Agile

A ideia sendo planejada aqui é a de um Site & App simples baseado na Missão Artemis, que foi a lua e voltou em 10 dias, enviando fotos e videos a terra.
O site e app se propõe a mostrar as fotos e videos enviados pelo projeto e também mostrar atualizações da missões, que são reportados pela NASA via API ou scraping basico do site oficial.
